# Lexi — английские слова на карточках

Простое веб-приложение для заучивания английских слов с переводом на русский. Статический сайт без сборки; наборы хранятся в браузере, а после входа по логину и паролю синхронизируются через Supabase.

## Возможности

- Свои наборы слов: по одной паре на строку (`apple — яблоко`, `run = бежать`, или две колонки из Excel/Google Таблиц). Несколько вариантов перевода — через запятую.
- Режимы:
  - **Карточки** — переворот по клику или пробелу, оценка «знаю / ещё учу»;
  - **Заучивание** — для каждого слова сначала выбор ответа, потом написание; ошибки возвращаются в очередь;
  - **Микс** — каждый вопрос случайно становится выбором ответа, написанием или «верно / неверно»;
  - **Выбор ответа** — один из четырёх вариантов;
  - **Написание** — ввод перевода; регистр, «ё», артикли, `to` и мелкие опечатки в длинных словах не мешают;
  - **Верно / неверно**;
  - **Подбор** — соединить 6 пар на время, с рекордом.
- Направление EN → RU, RU → EN или вперемешку; режим «только невыученные»; звуки правильного и неверного ответа (отключаются на странице набора).
- Озвучка английского голосом браузера: автоматически выбирается самый качественный из установленных (Natural, Premium/Enhanced, Google), его можно сменить на странице набора. На macOS и iOS качественные голоса можно докачать: «Универсальный доступ → Устная речь → Системный голос → Управление голосами».
- Картинки к словам (после входа): поиск фото на Pexels по английскому слову или загрузка своего. Картинка показывается вместе с переводом: на карточке, в вопросах, вариантах ответа и в «Подборе».
- Прогресс по каждому слову (уровень 0–5, «выучено» с уровня 3).
- «Поделиться» — ссылка, в которой закодирован весь набор; получатель добавит его к себе в один клик.
- Горячие клавиши: `1–4` — варианты, `←/→` — оценка или ответ «верно / неверно», `Enter` — продолжить.

Без входа данные хранятся только в `localStorage` браузера. После входа наборы и прогресс сохраняются в облаке и доступны на любом устройстве; наборы, созданные до входа, загружаются в аккаунт.

## Запуск локально

Откройте `index.html` в браузере. Для копирования ссылки в буфер обмена лучше запустить локальный сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## Синхронизация через Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. SQL Editor → выполните [`supabase/schema.sql`](supabase/schema.sql).
3. Authentication → Sign In / Providers → Email: выключите **Confirm email**. Вход сделан по логину и паролю, письма никуда не отправляются.
4. Project Settings → API: скопируйте Project URL и publishable (anon) key в [`js/config.js`](js/config.js). Ключ публичный, доступ к данным ограничен политикой RLS: каждый видит только свои наборы.

Логин хранится в Supabase как служебный адрес `<логин>@lexi-cards.local`. Восстановления пароля нет: забытый пароль можно сменить только вручную в панели Supabase (Authentication → Users).

Если `js/config.js` пустой, приложение работает без облака.

### Картинки

1. SQL Editor → выполните [`supabase/images.sql`](supabase/images.sql): создаётся публичное на чтение хранилище `images`, загружать и удалять файлы можно только в своей папке.
2. Получите бесплатный ключ на [pexels.com/api](https://www.pexels.com/api/).
3. Edge Functions → Secrets: добавьте `PEXELS_API_KEY` с этим ключом.
4. Edge Functions → Deploy a new function → Via Editor: имя `image-search`, код из [`supabase/functions/image-search/index.ts`](supabase/functions/image-search/index.ts). В настройках функции выключите **Verify JWT**: функция сама проверяет, что пользователь вошёл.

Фото сжимаются в браузере до 512 px, поэтому бесплатного 1 ГБ в Supabase Storage хватит на десятки тысяч картинок. Найденные на Pexels фото не занимают место: хранится только ссылка.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте в него эту папку.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.
